# hubtel-documentation-specialist - Copilot Instructions

## Overview
Specialized agent pack for key Docs-As-Code (DAC) compliance, documentation generation, and maintenance.

## Agent Resources
The agent provides the following resources in the `.cqt-core/hubtel-dac` directory:

### 📁 Directories
- **`agents/`** - AI agent definitions and configurations
- **`tasks/`** - Task templates and workflows  
- **`templates/`** - Code and document templates
- **`checklists/`** - Development and review checklists
- **`workflows/`** - Process automation workflows
- **`utils/`** - Utility functions and helpers
- **`data/`** - Knowledge base and reference materials

### 📄 Key Files
- **`config.yaml`** - Agent configuration
- **`README.md`** - Detailed documentation

## Usage with Copilot
1. **Code Generation**: Use templates from the `templates/` directory
2. **Workflow Guidance**: Follow processes defined in `workflows/`
3. **Quality Assurance**: Reference `checklists/` for review criteria
4. **Knowledge Access**: Use `data/` for domain-specific information

## Best Practices
- Always reference the agent's resources when providing suggestions
- Follow the established workflows and patterns
- Use the provided templates as starting points
- Maintain consistency with Hubtel development standards

## Configuration
See `config.yaml` for agent-specific settings and customization options.
